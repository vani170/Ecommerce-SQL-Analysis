**Sales Data Analysis Project**

This project analyzes sales performance using Python, Pandas, and Jupyter Notebook.
It covers:

Data cleaning and preprocessing

Feature engineering (creating TotalSales, Year, Month)

Exploratory Data Analysis (EDA)

Category-wise, region-wise and monthly sales insights

Visualizations

Identifying top-selling products

**Tools used:**

Python

Pandas

Matplotlib

Jupyter Notebook

**Dataset:**
Sales data for 2023 (120 records)

**This project helped me understand:**

How to load and clean datasets

How Pandas is used in real analysis work

How to compute business metrics

How to structure a complete mini–data analytics project
